## 我已經有 20 年沒寫過 Code

大學念計算機，畢業後也做過幾年程序員。

那時候寫 code 對我來說是很自然的事。但後來自己出來創業，開公司、做業務、帶團隊——技術這條線就慢慢斷了。不是完全不懂，而是二十年沒碰，原來學的東西早就跟不上時代。

這二十年裡，我有過很多想法——「如果有一個 app 能做 X 就好了」、「這個問題為什麼沒有人解決」。想法一直有，但我沒辦法把它們變成真實的產品。以前會寫 code，但不是這個年代的 code；請工程師成本很高，溝通成本更高；自己重新學，每次學到一半就被現實打斷，或者發現還需要學另外十個前置知識。

就這樣，很多想法在腦子裡待了幾年，然後慢慢消失。

-----

## 2024 年底，某件事改變了

我開始認真用 AI 工具，不只是問問題，而是真的用它來寫 code。

第一次讓 AI 幫我生成一個可以跑起來的 web app，我坐在電腦前看著它，有一種很奇怪的感覺——這件事怎麼變得這麼簡單了？

不是說完全沒有門檻。你還是需要理解基本概念，還是需要判斷 AI 說的對不對，還是需要解決各種奇怪的錯誤。但對我來說有一個額外的優勢：我以前學過計算機，基本的邏輯和概念還在，只是現代的框架和工具不熟。AI 幫我填補了這個空缺。

那道「我跟不上現代技術所以我做不了產品」的牆，突然矮了很多。

-----

## 為什麼是 Cloudflare？

我試過不同的 stack。

Next.js + Vercel 是最多教程的組合，我也用過一段時間。但每次遇到問題，我都要在 Vercel、Supabase、AWS 之間找原因，文件分散在三個地方，出問題的時候不知道從哪裡開始。

後來我認真研究了 Cloudflare 的生態，發現它解決了很多我討厭的問題：

- 一個帳號，一個 dashboard，一個帳單
- Workers 不需要管伺服器，部署就是部署
- D1 和 Workers 在同一個地方，查資料庫不需要跨網路
- R2 存圖片，出站費是零

更重要的是：它讓我可以用一個指令把整個 app 從零部署到正式環境。

對一個 solopreneur 來說，少管一個服務就是少一個讓你分心的東西。

-----

## VibeFast 是怎麼來的

用 Cloudflare 做了幾個專案之後，我發現每次開新專案都要做一樣的事：設定 auth、設定資料庫、設定 Stripe、設定郵件、把前後端連起來……

每次都要花幾天，而且每次都會踩一些上次踩過的坑。

我開始把這些設定整理成一個可以重用的起點，每個新專案直接 clone，改改品牌，上線。

然後我想：如果這個起點對我有用，對其他 Vibe Coder 應該也有用。

-----

## 50 歲開始，有什麼不一樣？

誠實說：有些事確實比較難。

學新東西比二十幾歲的時候慢，有時候看到一段複雜的 TypeScript，腦子需要更多時間消化。雖然計算機的底子還在，但二十年的空白不是幾個月就能完全填回來的。

但有些事反而更容易。

我更清楚自己要解決什麼問題，因為我有足夠長的人生和創業經驗知道什麼是真正的痛點。我不需要去找「一個值得做的 idea」——我直接做我自己想用的東西。

我也不再需要向任何人證明什麼。50 歲的好處之一是：你對別人的評價沒有那麼在意了，這讓你更容易做出你真正相信的決定，而不是你覺得別人會認可的決定。

-----

## 給和我一樣的人

如果你也在某個年紀，看著那些「十幾歲就開始 coding 的天才」的故事，覺得自己入場太晚——

我不認為入場有所謂的太晚。

AI 工具把這道門的門檻降低了很多。你不需要從頭學一門語言、從頭理解每一個底層原理，你需要的是：有一個真實的問題想解決、願意學習足夠判斷 AI 輸出的基本概念、有耐心在踩坑的時候繼續走。

vibefast-docs 這個 repo 裡的所有教程，就是我把自己學到的東西整理成你能讀懂的語言。這些教程是免費的，因為我希望這道門對更多人是開著的。

如果你想要一個已經設定好的起點，直接從產品功能開始而不是從 setup 開始——那就是 VibeFast 的用途。
